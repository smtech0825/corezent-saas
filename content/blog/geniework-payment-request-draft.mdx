계약 정보만 넣으면 부가세와 선금 공제가 계산된 청구 기안문이 나옵니다.

실제 공사 사례로 과정을 보여드립니다.

지난 편에서는 계약·발주 사용법을 보여드렸습니다.

이번 편은 그 흐름의 마지막 단계인 **대금 청구**입니다.

발주하고 계약하고 검수까지 끝났으면 남은 건 대금을 지급하는 일인데, 여기서 부가세와 선금 공제 계산이 헷갈리기 시작합니다.

오늘은 실제 사례로 따라가 보겠습니다.

> **도담시 청사 외벽 방수공사**
> **새도담건설(주)에 공급가 5,000만 원을 청구하는 건입니다.**

## 이 기능은 입력이 짧습니다

앞서 다룬 예산 편성이나 결산 보고서는 입력할 게 많았는데, 대금 청구는 반대입니다.

필수 입력이 **딱 세 개**뿐입니다.

- 계약 건명
- 계약업체
- 청구금액(공급가)

나머지는 선택이거나 자동 계산입니다. 그래서 익숙해지면 1~2분이면 끝납니다.

## 1단계 : 계약 정보 넣기

오늘 사례는 이렇게 채웠습니다.

- **계약 건명 : 도담시 청사 외벽 방수공사**
- **계약업체 : 새도담건설(주)**
- **청구금액(공급가) : 50,000,000원**
- **계약일자 : 2026-03-02**
- **준공·납품일자 : 2026-06-15**

계약일자와 준공일자는 선택 항목이지만, 넣어두시길 권합니다.

기안문 본문에 "2026. 3. 2. 체결한 계약에 따라 2026. 6. 15. 준공 완료된 공사의 대금을 청구함" 같은 문장으로 자연스럽게 들어가기 때문입니다.

이 두 날짜가 없으면 문장이 밋밋해집니다.

## 2단계 : 부가세 방식 고르기 (포함인가 별도인가)

여기가 첫 번째 갈림길입니다.

청구금액 5,000만 원이 **부가세를 포함한 금액인지, 별도인지** 를 골라야 합니다.

- **부가세 별도** : 5,000만 원이 공급가액. 부가세 500만 원을 더해 총 5,500만 원 청구
- **부가세 포함** : 5,000만 원 안에 부가세가 들어 있음. 공급가액은 약 4,545만 원, 부가세는 약 455만 원

같은 5,000만 원인데 총액이 500만 원이나 차이 납니다.

**계약서에 "부가세 별도"라고 적혀 있는지 먼저 확인**하고 고르셔야 합니다.

오늘 사례는 입력값이 "청구금액(공급가)"이므로 별도 방식입니다.

![지니워크 대금 청구 기안문 : 부가세·선금 공제 자동 계산 화면 2](/blog/geniework-payment-request-draft/02.png)

## 3단계 : 선금이 있다면 (없으면 건너뜁니다)

선금을 미리 지급한 계약이라면 이번 청구에서 그만큼 빼야 합니다. 관련 입력칸은 세 개입니다.

- **선금 수령액(원)** : 업체가 이미 받아간 금액
- **선금 부가세** : 선금에도 부가세가 포함됐는지
- **선금 공제율(%)** : 이번에 몇 %를 공제할지. **비워두면 전액 공제** 됩니다

공제율 칸이 있는 이유는, 공사가 여러 차례에 나눠 청구되는 경우 선금도 나눠서 공제하는 방식을 쓰기 때문입니다. 한 번에 다 빼려면 비워두시면 됩니다.

**여기서 중요한 것 : 안 넣은 값은 지어내지 않습니다**

오늘 사례에서 AI 지시에 이렇게 적었습니다.

> 청구 잔금 산출 근거(부가세·선금 공제)를 표로 명확히 하고, 선금 정산 근거 법령을 명시할 것.
> **입력에 없는 금액·날짜는 지어내지 말 것.**

만약 선금 수령액을 입력하지 않았다면, 앱은 **선금 금액을 임의로 만들어내지 않습니다.**

없는 숫자를 채워 넣는 대신 그 부분을 비워두거나 확인이 필요하다고 표시합니다.

대금 청구는 금액이 그대로 지급으로 이어지는 문서라, 이 부분이 특히 중요합니다.

숫자 하나가 틀리면 과지급이나 과소지급이 되니까요.

## 4단계 : 첨부 서류 고르기

기안문에 함께 붙일 서류 목록을 체크로 고릅니다. 계약 형태에 따라 필요한 서류가 다릅니다.

| **계약 형태** | **주로 붙는 서류** |
| --- | --- |
| 공사 | 준공검사조서, 세금계산서, 완납증명서 |
| 물품 | 납품확인서, 검수조서, 세금계산서 |
| 용역 | 검수조서, 결과물, 세금계산서 |

오늘 사례는 공사이므로 준공검사조서가 포함됩니다.

체크한 항목이 기안문 마지막 "붙임" 목록으로 정리되어 나옵니다.

## 5단계 : 결과 확인

생성하면 대금 청구 기안문 한 종과 첨부 서류 목록이 나옵니다.

본문에는 **청구 잔금 산출 근거가 표**로 들어갑니다.

표 구성은 대략 이런 형태입니다.

| **구분** | **금액** |
| --- | --- |
| 공급가액 | (입력한 청구금액) |
| 부가세 | (자동 계산) |
| 소계 | (자동 계산) |
| 선금 공제액 | (선금 입력 시 자동 계산) |
| **실지급액** | **(자동 계산)** |

**이 계산은 전부 계산 로직이 처리하고 AI는 관여하지 않습니다.**

부가세율을 곱하는 것도, 선금을 빼는 것도 프로그램이 합니다.

## 6단계 : 내보내기

한글(HWPX)·PDF로 받을 수 있습니다.

## 발송 전 확인할 것 3가지

기안문이 나왔다고 바로 올리지 마시고, 아래 세 가지는 눈으로 확인하시길 권합니다.

- **부가세 방식이 계약서와 맞는가** : 포함/별도를 잘못 고르면 총액이 통째로 달라집니다
- **선금 공제액이 실제 지급한 선금과 맞는가** : 지급 기록과 대조
- **첨부 서류가 실제로 다 준비됐는가** : 목록에는 있는데 실물이 없으면 반려됩니다

## 정리

계약 정보(건명·업체·금액)

→ 부가세 방식

→ (있으면) 선금 정보

→ 첨부 서류

→ AI 지시

→ 생성

→ 확인

→ 다운로드.

입력은 짧지만 2단계(부가세 방식)와 3단계(선금)만 정확히 고르면, 나머지 계산은 전부 자동으로 맞아떨어집니다.
