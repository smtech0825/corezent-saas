예산서와 실집행 엑셀만 올리면 집행률·이월·불용까지 계산된 결산 보고서가 나옵니다.

매칭부터 완성까지 과정을 보여드립니다.
지난 편에서는 예산 편성 사용법을 보여드렸습니다.

이번 편은 그 짝이 되는 기능, **결산 보고서**입니다. 예산 편성이 "쓸 계획"을 만드는 기능이라면, 결산은 "쓴 결과"를 정리하는 기능입니다.

이 기능은 다른 기능과 시작점이 다릅니다.

글을 쓰는 게 아니라 **엑셀 파일 두 개를 올리는 것부터** 시작합니다.

## 시작하기 전에 : 예시 카드부터 열어보세요

입력 단계가 두 단계(매칭 → 계산)로 나뉘어 있어서, 처음이라면 앱 안의 **예시 결산보고서 카드**를 먼저 열어보시길 권합니다.

도담시 일자리경제과 세출결산 사례가 들어 있는데, 3개 사업에 사고이월 6,000만 원·불용 2,400만 원·집행률 81.33%까지 계산이 끝난 완성본을 바로 볼 수 있습니다.

엑셀을 다시 올리거나 계산을 새로 하지 않고 결과만 열립니다.

## 1단계 : 결산 기본 정보

- 결산명 (필수)
- 회계연도 · 소관 부서
- 결산 개요 (결산 범위나 주요 변동 사항)
- 미공개 자료 체크박스

결산 자료는 확정 공개 전에 다루는 경우가 많으니, 필요하면 **미공개 자료** 체크를 켜서 이 PC 안에서만 처리되게 할 수 있습니다.

![지니워크 결산 보고서 : 엑셀 두 개로 집행률까지 화면 3](/blog/geniework-settlement-report/03.png)

## 2단계 : 엑셀 두 개 올리기

- **예산서 엑셀** (필수) : 예산현액의 기초가 되는 자료
- **실집행 엑셀** (필수) : 지출액의 기초가 되는 자료
- **감사 지적사항 PDF** (선택) : 있으면 키워드를 자동으로 뽑아 점검 항목에 반영

감사 지적사항 PDF는 있으면 넣어두시길 권합니다. 문서에서 핵심 키워드를 자동으로 뽑아내서, 결산 보고서의 점검 항목에 그 내용이 반영됩니다.

![지니워크 결산 보고서 : 엑셀 두 개로 집행률까지 화면 4](/blog/geniework-settlement-report/04.png)

## 3단계 : 어느 열이 무엇인지 알려주기 (컬럼 매핑)

기관마다 엑셀 양식이 다르기 때문에, 어느 열이 사업명이고 어느 열이 금액인지 지정해줘야 합니다. 드롭다운으로 짝을 맞추는 방식입니다.

- 예산서 : 사업명 / 금액 / 과목 / 이월액 등
- 실집행 : 사업명 / 금액 / 과목 등

여기서 지정한 열이 결산 계산의 기준이 되므로, 이 단계만 정확히 맞추면 나머지는 자동입니다.

![지니워크 결산 보고서 : 엑셀 두 개로 집행률까지 화면 5](/blog/geniework-settlement-report/05.png)

## 4단계 : 사업명 매칭 확인

두 엑셀의 사업명을 자동으로 짝지어 줍니다.

괄호나 공백, 기호가 조금 다른 정도는 알아서 같은 사업으로 인식합니다.

예를 들어 예산서에는 "청년 일자리 지원사업", 집행 파일에는 "청년일자리지원 사업"으로 되어 있어도 같은 사업으로 매칭됩니다.

다만 자동으로 확신하기 어려운 건은 따로 표시되므로, 그것만 눈으로 확인하고 확정하면 됩니다.

이미 다른 사업에 짝지어진 항목은 선택이 막혀 있어서, 실수로 한 사업에 두 개를 붙이는 일이 생기지 않습니다.

## 5단계 : 이월액 분류하기 (이월 태깅)

결산에서 가장 신경 쓰이는 부분입니다. 이월된 금액이 있다면 그 성격을 골라줘야 합니다.

- 명시이월
- 사고이월
- 계속비이월

앞서 본 예시에서는 전통시장 관련 사업의 6,000만 원이 **사고이월**로 분류되어 있었습니다. 이렇게 유형과 사유를 지정해두면, 완성된 보고서의 이월 명세서에 유형별로 정리되어 들어갑니다.

## 6단계 : 전년 결산 입력 (선택)

전년도 사업명과 예산·지출액을 넣어두면, 전년 대비 증감 표가 함께 만들어집니다. 전년 자료가 없는 사업은 표에서 "-"로 표시되므로, 일부만 넣어도 괜찮습니다.

## 7단계 : 감사 지적 키워드와 단수 처리

- 감사 지적 키워드 : PDF를 올렸다면 자동으로 채워지고, 직접 추가·수정도 됩니다
- 단수 절사 : 원 단위 / 천 원 단위

![지니워크 결산 보고서 : 엑셀 두 개로 집행률까지 화면 7](/blog/geniework-settlement-report/07.png)

## 8단계 : 계산과 생성

계산 버튼을 누르면 아래가 자동으로 산출됩니다.

- **예산현액** : 세출예산 + 전년 이월 + 예비비 + 전용 + 이용 + 수입대체경비
- **집행률** : 지출액 ÷ 예산현액
- **이월액** : 태깅한 유형별 합계
- **불용액** : 남은 금액

앞서 본 예시에서 집행률 81.33%가 나온 것도 이 계산의 결과입니다. **이 계산은 전부 계산 로직이 처리하고 AI는 관여하지 않습니다.** 부서별 합계가 총괄 합계와 맞는지도 자동으로 검증해서, 어긋나면 경고를 띄웁니다.

계산이 끝나면 결산 보고서 **8종**이 묶음으로 생성됩니다.

## 9단계 : 표와 차트 확인

결산 보고서에는 여러 표가 들어갑니다. 결산 총괄표, 집행 현황표, 부서별·과목별 내역, 이월 명세서, 불용액 명세, 전년 대비 증감표 등입니다. 차트도 함께 만들어져서 문서에 삽입됩니다.

표는 엑셀로 따로 내보낼 수 있는데, 이때 **수식이 살아 있는 상태로** 나옵니다. 숫자만 박힌 게 아니라 계산식이 들어 있어서, 엑셀에서 값을 바꾸면 합계가 다시 계산됩니다.

## 10단계 : 내보내기

한글(HWPX)·PDF로 받을 수 있고, 8종 전체를 ZIP 하나로 받는 것도 됩니다. 표만 따로 엑셀로 받는 것도 가능합니다.

## 이 기능에서 꼭 알아두실 것

**엑셀 병합 셀 처리에 안전장치가 있습니다.**

엑셀에서 셀이 병합되어 있으면 빈칸이 생기는데, 이걸 채워 넣는 처리를 하되 **금액 열에는 절대 적용하지 않습니다.**

금액이 잘못 복제되면 결산 전체가 틀어지기 때문에, 아예 막아둔 구조입니다.

**정리**

기본 정보

→ 엑셀 두 개 업로드

→ 컬럼 매핑

→ 사업명 매칭 확인

→ 이월 태깅

→ (선택) 전년 결산

→ 감사 키워드·단수

→ 계산·생성

→ 표·차트 확인

→ 내보내기

손이 가는 건 컬럼 매핑과 이월 태깅 두 군데뿐이고, 나머지 계산은 전부 자동입니다.
