매주 반복되는 주간보고, 이월 건 챙기는 것부터가 일입니다.

지니워크 업무보고서 기능으로 실제 25주차 보고서를 만드는 과정을 보여드립니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 1](/blog/geniework-weekly-work-report/01.jpg)

지난 편에서는 현안보고서 사용법을 보여드렸습니다.

이번 편은 메뉴 순서상 다음 기능인 **업무보고서**입니다.

매주(또는 매월) 반복해서 써야 하는 문서라 형식이 손에 익긴 하지만, 지난주 이월 건을 빠뜨리지 않고 챙기는 일이 은근히 신경 쓰입니다.

오늘은 실제로 만든 "2026년 25주차 업무보고서"를 예시로 보여드리겠습니다.

## 1단계 : 보고 주기 고르기

업무보고서에 들어가면 먼저 주간·월간·분기·연간 중 보고 주기를 고릅니다.

오늘 예시는 **주간**입니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 2](/blog/geniework-weekly-work-report/02.png)

## 2단계 : 보고 기간 정하기

시작일을 고르면 종료일이 자동으로 계산됩니다.

주간이면 시작일 기준으로 그 주의 마지막 날까지, 몇 주차인지도 함께 표시됩니다.

오늘 예시는 시작일을 2026. 6. 15.로 넣었더니 종료일 2026. 6. 19., **25주차**로 자동 계산됐습니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 3](/blog/geniework-weekly-work-report/03.png)

## 3단계 : 보고자·수신자 입력

- **보고자 :**안전건설과 주무관 김도현
- **수신자 :**안전건설과장

이 두 칸은 완성된 보고서의 머리글에 그대로 표기됩니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 4](/blog/geniework-weekly-work-report/04.png)

## 4단계 : 지난주 미완료 항목 이어받기

여기가 이 기능에서 가장 편한 부분입니다.

지난주 보고서에서 "진행 중"으로 남겨둔 항목이 있으면 체크박스로 목록이 뜨고, 체크한 항목은 이번 보고서에 자동으로 이어져 반영됩니다.

오늘 예시에서는 "어린이놀이시설 합동 안전점검 결과 보고서 작성"이 전주 이월 건으로 체크되어, 이번 보고서의 "1. 주요 업무" 항목에 "○ 이월"이라는 표시와 함께 자동으로 포함됐습니다.

매번 지난주 보고서를 다시 열어 이월 건을 찾아 옮겨 적을 필요가 없다는 뜻입니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 5](/blog/geniework-weekly-work-report/05.png)

## 5단계 : 이번 기간 업무 내역 입력

이번 주에 한 일을 자유롭게 적습니다.

항목별로 정리해서 적어도 되고, 오늘 예시처럼 아래 내용을 그대로 넣어도 됩니다.

> 관내 어린이놀이시설 합동 안전점검 1차 실시(동부권 16개소 완료, 부적합 2개소 개선계획 접수).
> 노후 보도육교 정밀안전진단 용역 착수계 검토·결재 완료(3개소 대상).
> 여름철 풍수해 대비 위험시설 일제점검 계획 수립 완료.
> 안전신문고 민원 처리(도로 파손 5건, 가로등 고장 3건, 전건 현장 조치 완료).

여기서 중요한 점은, 이 내용 하나만 넣어도 완성된 보고서에서는 "1. 주요 업무"뿐 아니라 "2. 추진 실적"에서 **완료된 것과 진행 중인 것이 자동으로 구분**되어 나온다는 점입니다.

오늘 예시에서는 위 네 가지가 전부 "완료"로, 4단계에서 이어받은 이월 건은 "진행 중(초안 완료, 내부 검토 중)"으로 자동 분류됐습니다.

완료/진행 여부를 따로 표시해서 적을 필요 없이, 서술한 내용에서 AI가 알아서 구분해 정리합니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 6](/blog/geniework-weekly-work-report/06.png)

## 6단계 : 다음 기간 계획 입력

다음 주에 할 일도 자유롭게 적습니다.

> 어린이놀이시설 합동 안전점검 2차 실시(서부권 14개소).
> 부적합 2개소 개선계획 이행 여부 현장 확인.
> 노후 보도육교 정밀안전진단 용역 착수(현장 조사 시작).
> 여름철 풍수해 대비 위험시설 일제점검 본격 추진.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 7](/blog/geniework-weekly-work-report/07.png)

## 7단계 : (선택) 새 섹션 추가

기본 항목(주요 업무·추진 실적·다음 계획) 외에 우리 부서만의 항목이 필요하면 섹션을 직접 추가할 수 있습니다. 예를 들어 "예산 집행 현황"이나 "직원 교육 이수 현황" 같은 항목이 필요한 부서라면 여기서 만들어 쓰면 됩니다. 오늘 예시에서는 기본 항목만으로 충분해 추가하지 않았습니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 8](/blog/geniework-weekly-work-report/08.png)

## 8단계 : AI 지시 (선택)

"완료 항목은 간결하게, 이월 건은 사유를 조금 더 자세히" 같은 방향을 지시할 수 있는 칸입니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 9](/blog/geniework-weekly-work-report/09.png)

## 9단계 : 결과 확인 및 다운로드

완성된 보고서는 "1. 주요 업무 → 2. 추진 실적(완료/진행 중 구분) → 3. 다음 주 계획" 순서로 정리되어 나옵니다. 지난주 이월 건이 이번 보고서 안에서 자연스럽게 "진행 중" 항목으로 이어지고, 나머지 업무는 항목기호(가·나·다 → 1·2·3)로 정리된 형태로 완성됩니다.

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 10](/blog/geniework-weekly-work-report/10.png)

![지니워크 사용법 : 업무보고서로 주간보고 매주 반복 작업 줄이기 화면 11](/blog/geniework-weekly-work-report/11.png)

## 정리

보고 주기 선택

→ 보고 기간

→ 보고자·수신자

→ 지난주 미완료 항목 이어받기

→ 이번 기간 업무 내역

→ 다음 기간 계획

→ (선택) 새 섹션·AI 지시

→ 생성

→ 다운로드.

특히 4단계(미완료 항목 이어받기)와 5단계(완료/진행 자동 구분)가 매주 반복되는 주간보고 작성 시간을 가장 많이 줄여주는 부분입니다.
