---
title: 2. Gemini API 키 발급 방법
description: 구글 계정으로 발급받아 지니워크에 넣는 5단계
---

**자료와 법령을 찾는 AI**입니다. 문서에 근거를 붙이거나 필요한 자료를 조사할 때 씁니다.

**구글 계정만 있으면 5분이면 됩니다.**

---

## 1단계 · Google AI Studio 접속

1. [Google AI Studio](https://aistudio.google.com)에 접속합니다.
2. 평소 쓰시는 **구글 계정**으로 로그인합니다. 따로 가입할 필요가 없습니다.
3. 처음 들어가면 약관 동의 화면이 나옵니다. 확인하고 **[Continue]** 를 누릅니다.

<Callout type="info">
  구글 계정이 없으시면 [여기](https://accounts.google.com/signup)에서 무료로 만들 수 있습니다.
</Callout>

---

## 2단계 · 키 발급받기

1. 왼쪽 메뉴에서 **[Get API key]** 를 누릅니다.
2. **[Create API key]** 를 누릅니다.
3. 프로젝트를 고르라는 창이 나오면, 처음이시면 **[Create API key in new project]** 를 누르면 됩니다.
4. 잠시 후 키가 만들어집니다. **[Copy]** 를 눌러 복사하고 메모장에 저장합니다.

<Callout type="warn">
  **키를 다른 사람에게 알려주거나 인터넷에 올리지 마세요.** 남이 쓰면 요금이 나갑니다.
</Callout>

<Callout type="info">
  키는 `AIza` 로 시작하는 긴 글자입니다.
</Callout>

---

## 3단계 · 무료로 쓸 수 있는 한도

Gemini는 **무료로 쓸 수 있는 한도**가 있습니다. 처음에는 결제 등록 없이 바로 쓸 수 있습니다.

<Callout type="info">
  지니워크에서 Gemini는 **자료를 찾을 때만** 씁니다. 문서를 만드는 일은 Claude가 하므로, 무료 한도만으로도 대부분 충분합니다.
</Callout>

한도와 조건은 바뀔 수 있습니다. 현재 기준은 공식 페이지에서 확인하세요.

**[Google AI 요금 안내](https://ai.google.dev/pricing)**

---

## 4단계 · 한도를 넘길 때 (필요한 경우에만)

무료 한도를 넘기거나 더 빠른 속도가 필요하면 결제를 등록하면 됩니다.

1. [Google Cloud Console](https://console.cloud.google.com)에 로그인합니다.
2. 왼쪽에서 **[결제(Billing)]** 를 골라 결제 계정을 만듭니다.
3. 카드를 등록하고 저장합니다.

<Callout type="info">
  대부분은 여기까지 갈 일이 없습니다. **무료 한도로 부족해질 때만** 하시면 됩니다.
</Callout>

---

## 5단계 · 지니워크에 키 넣기

1. 지니워크를 실행합니다.
2. **설정** 메뉴를 누릅니다.
3. **API 키** 메뉴로 들어갑니다.
4. Gemini 키 넣는 칸에 복사해 둔 키를 붙여넣습니다. **Ctrl+V**
5. 저장합니다.
6. 저장하면 **초록 불이 켜지고 "연결됨"** 이라고 나옵니다. 그러면 제대로 들어간 것입니다.

<Callout type="warn">
  **초록 불이 안 켜지면** 키를 복사할 때 앞뒤가 잘리지 않았는지, 인터넷이 연결돼 있는지 확인해 보세요.
</Callout>

<Callout type="info">
  **직접 타이핑하지 마세요.** 반드시 복사해서 붙여넣으세요.
</Callout>

<Callout type="success">
  **두 칸 모두 초록 불이 켜지면** 지니워크의 모든 기능을 쓸 수 있습니다.
</Callout>
