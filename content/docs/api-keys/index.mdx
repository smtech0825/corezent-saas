description: 발급 전에 알아두실 것과 키를 넣는 위치
---

지니워크를 쓰려면 **키 두 개가 모두 필요합니다.**

| 어느 AI | 무슨 일을 하나 |
|---|---|
| **Claude** | 문서를 만듭니다 |
| **Gemini** | 자료와 법령을 찾습니다 |

**하나만 넣으면 일부 기능이 작동하지 않습니다.** 두 개를 모두 발급받아 넣어 주세요.

**왜 직접 발급하나요?** 지니워크는 자체 AI 키를 갖고 있지 않습니다. 본인 키를 쓰면 중간 마진 없이 쓴 만큼만 청구되고, 사용 한도를 직접 정할 수 있으며, 판매사를 거치지 않고 본인 계정과만 직접 통신합니다.

**넣는 곳은 두 키 모두 같습니다** — 지니워크 실행 → **설정** → **API 키**
